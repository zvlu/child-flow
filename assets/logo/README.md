# Sprout logo assets

Drop the official logo files here. Once they're in, I'll wire them into:

- iOS app icons for both targets (Sprout staff app + SproutFamily parent app)
- Web app branding (header, login screen, favicon)

Suggested files (matching the lockups you shared):

- `logo-color.png` (or `.svg`) — original color mark, square, transparent background
- `logo-horizontal.png` (or `.svg`) — horizontal lockup (mark + wordmark side by side)
- `logo-vertical.png` (or `.svg`) — vertical lockup (mark above wordmark)

SVG is preferred if you have it — it scales cleanly to every icon size without me needing to re-derive it. PNG is fine too; just use the highest resolution you have (ideally 1024x1024 or larger for the mark).
